# OBD Libre

Escáner OBD-II (ELM327 por Bluetooth clásico o WiFi) sin funciones bloqueadas.

## Obtener el APK (gratis, ~5 min)
1. Crea una cuenta en github.com y un repositorio nuevo (privado o público).
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
3. Abre la pestaña **Actions** > «Compilar APK» > espera el check verde.
4. Entra a esa ejecución y descarga **OBD-Libre-APK** (zip con `app-release.apk`).
5. Instala el APK en Android (permitir orígenes desconocidos).

Si falla la compilación, copia el error rojo del paso que falló y envíalo.
